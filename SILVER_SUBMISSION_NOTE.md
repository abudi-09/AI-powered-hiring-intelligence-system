# Silver Repository Submission Note

## Project ownership

This repository is my ongoing personal side project. I authored the codebase and retain full intellectual property rights. It is not employer-owned code, not proprietary third-party code, and not submitted coursework.

## What this project is

AI-Powered Hiring Intelligence Systems is a FastAPI backend I am building to explore candidate–job matching, hiring analytics, and recruiter-facing intelligence APIs. It uses async PostgreSQL, Alembic migrations, JWT authentication, and several deterministic “engine” modules for scoring and analytics.

## Why it is not a class assignment

- There is no course rubric, instructor submission deadline, or academic institution affiliation tied to this repo.
- The architecture and feature set grew from my own product ideas for hiring workflows, not from a tutorial checklist.
- Commits reflect iterative personal development (models, migrations, engines, APIs), not a single graded deliverable.
